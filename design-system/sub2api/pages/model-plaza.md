# 模型广场改版

## 设计

首屏的主任务是查价格。类型导航放在搜索和分组筛选上方，正文按「模型类型 → 分组 → 价格」排列。借鉴参考截图中的对齐价目表，沿用 Sub2API 的 Indigo & Cyan 令牌、系统字体和等宽价格数字。桌面与手机均使用页面纵向滚动。窄屏允许价表单独横向滚动，并固定首列。类型导航由当前可见目录生成，搜索时保持稳定。

```text
模型广场                            登录
[全部] [文本] [图像] [视频] …
[搜索模型名称]           [全部分组 ▾]
文本
  分组名称                 倍率
  模型                  折后价 / 官方价
图像
  分组名称                 倍率
  模型                  按实际计费单位
暂未配置模型的分组
```

## 数据契约

公开目录保留全部活跃公开分组，空组单列。私有分组由服务端按明确授权或有效订阅裁剪，广场展示与 API Key 实际绑定权限独立。匿名入口继续受站点设置约束，个性化响应禁止缓存。模型用途由服务端分类，缺少可靠依据的模型显示为「其他」。价目表沿用已有币种、单位、倍率、分时和阶梯计算。

## 本地验收

- Go 普通与 unit 两档模型广场定向通过，覆盖公开和授权空组、匿名和无授权私有组隔离、订阅权限及分类。
- 前端 65 个价格、分组、筛选和双语定向用例通过，vue-tsc 类型检查通过。
- 本地 Chromium 使用模拟 API 验证 1440 与 320 像素视口、类型切换、首个价格、模型列固定及整页宽度。授权和未授权用例验证私有组渲染、退出后的清理。权限判定本身由 Go handler 定向测试验证。
