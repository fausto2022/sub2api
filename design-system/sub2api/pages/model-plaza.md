# 模型广场

## 设计

模型广场是只读目录。顶部按密钥管理页的规则和顺序提供 Anthropic、OpenAI、国产模型、其他四类筛选；无可见分组的厂商不可选。默认显示第一个有分组的厂商及其全部分组。桌面左侧为分组索引，手机改为分组选择器；切厂商会重置分组选择。搜索按模型名称过滤，不改变分组选项。空分组仍可选择，显示「暂无模型」。

```text
模型广场
[Anthropic] [OpenAI] [国产模型] [其他]
[分组索引]          [搜索模型名称]
                   分组名称   倍率
                   模型       折后价       官方价
```

报价只保留官方价和折后价；币种、计费单位、折扣、阶梯及分时价格保持原有口径。目录价不独立展示，不修改管理员定价或扣费。窄屏将两类价格排在模型名前后的纵向阅读路径中，桌面保留对齐价表。

## 数据与权限边界

只使用模型广场接口返回的可见分组，保留活跃公开组和已授权的私有组。分组名称直接使用接口本地化名称，内部按 ID 区分；模型类型字段保留兼容性，但不作筛选依据。模型广场不读取密钥绑定资格，不提供创建、跳转、预填或可选标签。

## 本地验收

- Go 普通与 `-tags=unit` 两档广场与分组权限定向测试通过。
- 前端 66 个目录筛选、价格、空组与双语定向用例通过，类型检查及定向 ESLint 通过。
- Chromium 使用模拟目录接口，覆盖 1440px 和 320px 下的厂商与分组筛选、模型搜索、报价金额（含零价）、空组和窄屏无横向溢出。模拟匿名、授权和未授权用户以及退出后的视图均符合接口数据边界，没有访问密钥或绑定资格接口。
