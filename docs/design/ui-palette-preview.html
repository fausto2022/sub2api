06

禁用项与迁移要点

禁用（Do Not）

  • 禁止外部字体 CDN（Google Fonts / Adobe Fonts）；中文字体走系统栈
  • 禁止 emoji 当图标，状态必须带文字或 SVG
  • 禁止组件内裸 hex / rgb，只用令牌类
  • 禁止把暗色做成亮色反色（用 ink 独立色阶，分开测对比度）
  • 禁止移除焦点环；禁止用 /60 低透明度环（2.31:1）
  • 禁止 primary-500 实心 + 白字（4.47:1）；实心用 600/700
  • 禁止用颜色单独表达状态（成功/警告/工单状态）
  • 禁止 dark-700 面 + dark-400 正文（4.16:1）
  • 禁止改名/删除既有 animation/keyframes
  • 禁止用 !important 或行内样式绕开令牌

迁移速查

  • text-gray-* / bg-gray-* → accent-*（页面底由 body 提供）
  • dark:text-white → dark:text-dark-50
  • dark:text-dark-500 正文 → dark-400（≥4.77:1）或 dark-300
  • text-primary-500 链接 → primary-600（亮）/ primary-400（暗）
  • focus:ring-* → focus-visible:ring-2 ring-primary-500（暗 primary-400）
  • 实心语义按钮：red-600/700、emerald-700/800、warning 深字浅底
  • 价格/用量列加 tabular-nums（表格已默认）
